Superstore

## Objective
Analyze sales and profit data to identify patterns, trends, outliers, and business insights.

## Dataset
Sample Superstore Dataset

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Data Cleaning
- Missing Value Analysis
- Descriptive Statistics
- Outlier Detection
- Correlation Analysis
- Data Visualization

## Key Findings
- Mean Sales = 229.86
- Median Sales = 54.49
- Mean Profit = 28.66
- Sales data contains outliers.
- Higher discounts often reduce profit.

## Conclusion
The project identifies important sales and profit trends using Exploratory Data Analysis techniques.
